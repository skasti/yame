Hva er YAME?

YAME betyr Yet Another Modem Emulator. Programmet kjører på Raspberry Pi og oppfører seg som et klassisk telefonmodem. Windows 98 sender modemkommandoer og internettdata gjennom en RS-232-seriekabel. YAME snakker PPP med Windows og videreformidler nettverkstrafikken.

Windows 98   <--- seriellkabel --->   Raspberry Pi / YAME
YAME gir en gammel datamaskin tilgang til dagens Internett.

Prøv kommandopaletten

  1. Se på skjermen som viser YAME.
  2. Trykk / (skråstrek) på tastaturet for å åpne kommandopaletten.
  3. Bruk pil opp/ned for å velge, eller skriv for å filtrere.
  4. Trykk Enter for å åpne et valg eller utføre en kommando.
  5. Trykk Esc for å gå tilbake eller lukke paletten.

Dette kan du utforske

Kommando Hva den gjør
/tone Slå de simulerte modemlydene på eller av.
/transformers Se hvordan YAME forenkler moderne nettsider.
/transformers/style-remover Velg on/off for fjerning av CSS og stilark.
/http-proxy HTTP- og HTTPS-kompatibilitet (ikke endre under vanlig demonstrasjon).
/fps Endre hvor raskt terminalbildet kan tegnes.
/clear-log Tøm loggen som vises på skjermen.

Andre nyttige taster

  • Tab: Bytt mellom DNS-, overførings- og proxyvisning når paletten er lukket.
  • Pil opp/ned: Marker et nettsted i proxyvisningen.
  • Enter eller pil høyre: Utvid et markert nettsted i proxyvisningen.
  • Pil venstre: Slå sammen et utvidet nettsted.
Pass på under demonstrasjonen: Ikke endre /port, /baud, /flow-control eller bruk /disconnect eller /quit uten hjelp. Det kan avbryte forbindelsen til Windows-PC-en.

Hva skjer når du åpner en nettside?

  1. Windows sender DNS- og TCP-trafikk gjennom modemforbindelsen.
  2. YAME henter data fra nettet på vegne av den gamle PC-en.
  3. Ved behov oversetter YAME HTTPS og rydder i HTML, slik at eldre nettlesere har større sjanse til å vise innholdet.
  4. Du kan følge med på aktiviteten i YAME-terminalen.

Merk: Når JavaScript og CSS fjernes, kan innholdet havne langt nede på siden. På Windows-maskinen må du ofte scrolle mye for å finne teksten.
